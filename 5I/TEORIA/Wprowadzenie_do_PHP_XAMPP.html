Wprowadzenie do PHP i XAMPP

Lekcja teoretyczna: czym jest PHP, gdzie jest wykorzystywany, jak działa aplikacja po stronie serwera oraz do czego służy lokalny pakiet serwerowy XAMPP.

1. Czym jest PHP?

PHP jest językiem programowania przeznaczonym przede wszystkim do tworzenia dynamicznych stron i aplikacji internetowych.

PHP = PHP: Hypertext Preprocessor. Jest to tzw. akronim rekurencyjny – pierwsza litera skrótu ponownie odnosi się do PHP.

PHP powstał w 1995 roku, a jego twórcą był Rasmus Lerdorf. Początkowo był prostym zestawem narzędzi do tworzenia stron WWW, lecz z czasem rozwinął się w pełnoprawny język programowania.

PHP jest projektem open source, czyli jego kod źródłowy jest publicznie dostępny, a z języka można korzystać bezpłatnie.

2. Do czego służy PHP?

PHP jest wykorzystywany przede wszystkim do programowania po stronie serwera. Może służyć do:

  • generowania dynamicznych stron WWW,
  • przetwarzania danych z formularzy HTML,
  • wykonywania obliczeń,
  • obsługi logowania i rejestracji użytkowników,
  • zarządzania sesją użytkownika,
  • obsługi plików na serwerze,
  • komunikacji z bazami danych,
  • dodawania, modyfikowania i usuwania danych,
  • tworzenia systemów CMS i sklepów internetowych,
  • tworzenia paneli administracyjnych i API.

PHP bardzo często współpracuje z systemami baz danych, takimi jak MySQL i MariaDB.

3. PHP jako język działający po stronie serwera

Strona klienta – client-side

Klientem jest najczęściej przeglądarka internetowa. To w niej wykorzystywane są przede wszystkim HTML, CSS oraz JavaScript.

Strona serwera – server-side

PHP działa przede wszystkim na serwerze. Przeglądarka wysyła żądanie, serwer uruchamia odpowiedni kod PHP, a następnie odsyła wynik.

PRZEGLĄDARKA → ŻĄDANIE → SERWER WWW → PHP → ODPOWIEDŹ → PRZEGLĄDARKA
Ważne: użytkownik strony nie otrzymuje kodu źródłowego PHP. Przeglądarka otrzymuje wynik działania programu, np. wygenerowany dokument HTML.

4. PHP a HTML, CSS i JavaScript

Technologie te nie są swoimi zamiennikami. Podczas tworzenia aplikacji internetowej najczęściej współpracują ze sobą.

5. Najważniejsze cechy PHP

Język interpretowany

Kod PHP jest wykonywany przez interpreter PHP. W typowej pracy nie tworzymy samodzielnie pliku wykonywalnego .exe.

Język skryptowy

PHP zaliczamy do języków skryptowych. Bardzo dobrze nadaje się do obsługi żądań internetowych i generowania treści.

Dynamiczne typowanie

Typ zmiennej może być ustalany na podstawie wartości przechowywanej przez zmienną i może zmieniać się podczas działania programu.

Programowanie proceduralne i obiektowe

PHP pozwala programować proceduralnie – z wykorzystaniem instrukcji i funkcji – oraz obiektowo – z wykorzystaniem klas i obiektów.

Wieloplatformowość

PHP może działać m.in. w systemach Windows, Linux i macOS. Wiele rzeczywistych serwerów internetowych z PHP działa pod kontrolą systemu Linux.

6. Zalety PHP

  • Stosunkowo niski próg wejścia – podstaw można nauczyć się dość szybko.
  • Łatwa współpraca z HTML i technologiami WWW.
  • Dobra obsługa baz danych, szczególnie MySQL i MariaDB.
  • Bezpłatność i dostępność na wielu systemach operacyjnych.
  • Duża liczba materiałów i dokumentacji.
  • Szerokie zastosowanie w istniejących stronach i aplikacjach internetowych.

7. Słabsze strony i ograniczenia PHP

  • W Internecie nadal znajduje się wiele starych i nieaktualnych przykładów PHP.
  • Język pozwala szybko napisać program, ale bez odpowiednich zasad równie łatwo stworzyć nieuporządkowany kod.
  • Nieprawidłowa obsługa danych użytkownika może prowadzić do problemów z bezpieczeństwem, np. SQL Injection lub XSS.
  • Ze względu na długą historię języka można spotkać pewne niespójności w starszych elementach PHP.
Współczesne PHP znacznie różni się od bardzo starych wersji języka. Dlatego podczas nauki należy korzystać z aktualnych materiałów i dokumentacji.

8. Gdzie spotykamy PHP?

PHP wykorzystywany jest zarówno w niewielkich witrynach, jak i rozbudowanych aplikacjach internetowych.

Jednym z najbardziej znanych systemów napisanych w PHP jest WordPress – popularny system zarządzania treścią (CMS).

Dla PHP istnieją również frameworki, np. Laravel i Symfony. Framework dostarcza gotowe narzędzia, biblioteki oraz strukturę ułatwiającą tworzenie większych aplikacji.

9. Dlaczego sam Visual Studio Code nie wystarczy?

Visual Studio Code pozwala napisać i edytować plik PHP. Do typowego uruchamiania aplikacji WWW potrzebujemy jednak odpowiedniego środowiska serwerowego.

SERWER WWW + PHP + BAZA DANYCH = LOKALNE ŚRODOWISKO DO NAUKI

Można instalować i konfigurować wszystkie składniki osobno. Na początku wygodniej jednak skorzystać z gotowego pakietu – XAMPP.

10. Co to jest XAMPP?

XAMPP jest bezpłatnym pakietem umożliwiającym szybkie uruchomienie lokalnego środowiska serwerowego.

XCross-Platform – wieloplatformowość
AApache – serwer WWW
MMariaDB – system zarządzania bazą danych
PPHP – język wykonywany po stronie serwera
PPerl – język programowania

11. Najważniejsze składniki XAMPP

Apache

Apache HTTP Server jest serwerem WWW. Odbiera żądania wysyłane przez przeglądarkę i zwraca odpowiednie zasoby.

PHP

XAMPP zawiera PHP, dzięki czemu lokalny serwer może wykonywać pliki z kodem PHP.

MariaDB

MariaDB jest systemem zarządzania relacyjnymi bazami danych. Będziemy go używać m.in. do przechowywania informacji o użytkownikach, produktach czy zamówieniach.

phpMyAdmin

phpMyAdmin jest aplikacją internetową pozwalającą zarządzać bazą danych za pomocą interfejsu graficznego. Umożliwia m.in. tworzenie baz i tabel, edycję rekordów, wykonywanie zapytań SQL oraz import i eksport danych.

12. Co oznacza localhost?

localhost oznacza komputer, na którym aktualnie pracujemy.

http://localhost

Standardowy adres IPv4 interfejsu lokalnego: 127.0.0.1

Wpisując http://localhost, nie łączymy się z odległym serwerem w Internecie. Przeglądarka komunikuje się z serwerem uruchomionym na naszym komputerze.

13. Katalog htdocs

W standardowej instalacji XAMPP w systemie Windows bardzo ważnym katalogiem jest:

C:\xampp\htdocs

Jest to domyślny katalog, z którego Apache udostępnia nasze projekty.

Jeżeli utworzymy katalog:

C:\xampp\htdocs\lekcja

to możemy odwołać się do niego w przeglądarce przez:

http://localhost/lekcja/

14. XAMPP Control Panel

Do wygodnego zarządzania usługami służy XAMPP Control Panel.

Podczas naszych zajęć najważniejsze będą:

  • Apache – potrzebny do obsługi aplikacji WWW i PHP,
  • MySQL/MariaDB – potrzebny, gdy aplikacja korzysta z bazy danych.
Zapamiętaj: jeżeli Apache nie jest uruchomiony, typowa strona PHP otwierana przez localhost nie będzie działać.

15. Instalacja XAMPP – podstawowe etapy

  1. Pobranie instalatora XAMPP z oficjalnej strony projektu Apache Friends.
  2. Uruchomienie instalatora.
  3. Wybranie potrzebnych składników.
  4. Wybór katalogu instalacji – w pracowni pozostawiamy standardowo C:\xampp.
  5. Zakończenie instalacji.
  6. Uruchomienie XAMPP Control Panel.
  7. Uruchomienie usługi Apache.
  8. W razie pracy z bazą danych – uruchomienie MySQL/MariaDB.
  9. Sprawdzenie działania przez wpisanie http://localhost w przeglądarce.

16. Jak będzie wyglądała nasza praca?

  1. Uruchamiamy XAMPP Control Panel.
  2. Uruchamiamy Apache.
  3. W razie potrzeby uruchamiamy MySQL/MariaDB.
  4. Tworzymy katalog projektu w htdocs.
  5. Otwieramy katalog projektu w Visual Studio Code.
  6. Tworzymy i edytujemy pliki projektu.
  7. Zapisujemy zmiany.
  8. Otwieramy aplikację w przeglądarce przez localhost.

18. Podsumowanie

PHP jest językiem wykorzystywanym przede wszystkim do tworzenia dynamicznych aplikacji internetowych po stronie serwera. Pozwala m.in. przetwarzać formularze, pracować z plikami, obsługiwać użytkowników oraz komunikować się z bazami danych.

Do nauki wykorzystamy XAMPP, który zapewni lokalne środowisko serwerowe. Najważniejszymi dla nas składnikami będą Apache, PHP, MariaDB oraz phpMyAdmin.
