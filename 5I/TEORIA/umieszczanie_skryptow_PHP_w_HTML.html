Umieszczanie skryptów PHP w dokumentach HTML

PHP może być umieszczany bezpośrednio pomiędzy elementami HTML. Dzięki temu jedna strona może zawierać zarówno statyczną strukturę dokumentu, jak i treści tworzone dynamicznie przez serwer.

1. HTML a PHP – przypomnienie

HTML opisuje strukturę strony internetowej. Przeglądarka interpretuje znaczniki HTML i na ich podstawie wyświetla nagłówki, akapity, obrazy, formularze i inne elementy.

PHP jest językiem wykonywanym po stronie serwera. Kod PHP jest przetwarzany przez interpreter PHP, a do przeglądarki użytkownika trafia przede wszystkim wynik działania skryptu, najczęściej w postaci kodu HTML.

Ważne: przeglądarka nie wykonuje kodu PHP. Kod PHP musi zostać przetworzony przez serwer wyposażony w interpreter PHP, np. Apache uruchomiony w pakiecie XAMPP.

2. Rozszerzenie pliku

Jeżeli dokument zawiera kod PHP, zapisujemy go standardowo z rozszerzeniem .php, np.:

index.php
kontakt.php
produkty.php

Sam kod HTML może znajdować się w pliku PHP bez żadnych zmian. Rozszerzenie .php informuje serwer, że dokument może zawierać kod wymagający przetworzenia przez interpreter PHP.

PlikTypowa zawartośćPrzetwarzanie PHP
index.htmlHTML, CSS, JavaScriptstandardowo nie
index.phpHTML, CSS, JavaScript oraz PHPtak

3. Znaczniki PHP

Kod PHP umieszczamy pomiędzy znacznikami:

<?php
    // kod PHP
?>

Otwarcie <?php oznacza początek kodu PHP, natomiast ?> jego zakończenie.

Najprostszy przykład

<?php
echo "Witaj na stronie!";
?>

Instrukcja echo wysyła tekst do wyniku generowanego przez skrypt.

4. PHP wewnątrz dokumentu HTML

Kod PHP można umieścić w wybranym miejscu dokumentu HTML.

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Pierwsza strona PHP</title>
</head>
<body>

    <h1>Moja strona</h1>

    <?php
    echo "Ten tekst został wygenerowany przez PHP.";
    ?>

</body>
</html>

Fragmenty znajdujące się poza znacznikami PHP są traktowane jako zwykły HTML. Fragment pomiędzy <?php i ?> jest wykonywany przez interpreter PHP.

5. Co otrzymuje przeglądarka?

Załóżmy, że na serwerze znajduje się następujący fragment:

<h2>Informacja</h2>

<?php
echo "<p>Strona działa poprawnie.</p>";
?>

Po wykonaniu PHP przeglądarka otrzyma wynik odpowiadający kodowi:

<h2>Informacja</h2>
<p>Strona działa poprawnie.</p>
Kod źródłowy PHP pozostaje na serwerze. Użytkownik strony otrzymuje wynik jego wykonania, a nie instrukcje PHP zapisane w pliku.

6. Instrukcja echo

echo jest bardzo często używana do wyświetlania danych lub generowania fragmentów HTML.

<?php
echo "Jan Kowalski";
?>

Możliwe jest również wygenerowanie znacznika HTML:

<?php
echo "<h2>Aktualności</h2>";
?>

Po przetworzeniu przez PHP tekst znajdujący się w cudzysłowie stanie się częścią kodu wysłanego do przeglądarki.

7. Łączenie HTML i PHP

Nie trzeba generować całej strony za pomocą instrukcji echo. Najczęściej stałe elementy strony zapisuje się bezpośrednio jako HTML, a PHP wykorzystuje się tylko tam, gdzie potrzebne są dane dynamiczne.

<h1>Dane użytkownika</h1>

<p>Imię:
    <?php
    echo "Jan";
    ?>
</p>

Takie podejście ułatwia czytanie kodu, ponieważ struktura HTML pozostaje widoczna.

8. Kilka fragmentów PHP w jednym dokumencie

W jednym pliku można wielokrotnie przechodzić pomiędzy HTML i PHP.

<?php
echo "<h1>Sklep komputerowy</h1>";
?>

<p>Witamy na naszej stronie.</p>

<?php
echo "<p>Zapraszamy do zapoznania się z ofertą.</p>";
?>

Interpreter wykonuje kolejne fragmenty PHP, natomiast zwykły HTML jest przekazywany do wyniku dokumentu.

9. Skrócona forma wyświetlania wartości

PHP udostępnia również składnię <?= ... ?>, która jest skrótem służącym do wyświetlania wartości.

<p>Nazwa szkoły: <?= "Technikum Informatyczne" ?></p>

Jest to odpowiednik:

<p>Nazwa szkoły:
<?php
echo "Technikum Informatyczne";
?>
</p>

10. Średnik w PHP

Większość instrukcji PHP kończymy średnikiem ;.

<?php
echo "Pierwszy tekst";
echo "Drugi tekst";
?>

Średnik informuje interpreter o zakończeniu instrukcji.

11. Komentarze w PHP

Komentarze nie są wykonywane. Służą programiście do opisywania kodu.

<?php

// komentarz jednoliniowy

# również komentarz jednoliniowy

/*
   komentarz
   wieloliniowy
*/

echo "PHP";

?>

12. Uruchamianie pliku PHP w XAMPP

Plik PHP powinien znajdować się w katalogu udostępnianym przez serwer Apache. W standardowej instalacji XAMPP w systemie Windows jest to katalog:

C:\xampp\htdocs\

Jeżeli utworzymy plik:

C:\xampp\htdocs\lekcja\index.php

po uruchomieniu Apache można odwołać się do niego w przeglądarce przez adres lokalnego serwera, np.:

http://localhost/lekcja/
Nie należy uruchamiać PHP przez zwykłe dwukrotne kliknięcie pliku. Dokument powinien zostać pobrany przez serwer WWW, aby kod PHP mógł zostać wykonany.

13. Jak przebiega wyświetlenie strony PHP?

  1. Użytkownik wpisuje adres strony w przeglądarce.
  2. Przeglądarka wysyła żądanie do serwera WWW.
  3. Serwer rozpoznaje plik PHP.
  4. Interpreter PHP wykonuje znajdujący się w nim kod.
  5. Powstaje wynik, najczęściej zawierający HTML.
  6. Serwer wysyła wynik do przeglądarki.
  7. Przeglądarka interpretuje otrzymany HTML i wyświetla stronę.

14. Najczęstsze błędy początkujących

  • zapisanie dokumentu ze skryptem jako .html zamiast .php,
  • brak uruchomionego serwera Apache,
  • otwieranie pliku bezpośrednio z dysku zamiast przez serwer,
  • brak średnika na końcu instrukcji,
  • niepoprawne zapisanie znacznika <?php,
  • problemy z cudzysłowami podczas generowania HTML za pomocą echo.

15. Podsumowanie

  • PHP jest wykonywany po stronie serwera.
  • Dokument zawierający PHP zapisujemy standardowo z rozszerzeniem .php.
  • Kod PHP umieszczamy pomiędzy <?php i ?>.
  • PHP może być przeplatany ze zwykłym kodem HTML.
  • echo pozwala wysyłać tekst i kod HTML do wyniku strony.
  • W jednym dokumencie może znajdować się wiele fragmentów PHP.
  • Do przeglądarki trafia wynik działania skryptu, a nie jego kod PHP.
  • W XAMPP pliki PHP uruchamiamy za pośrednictwem serwera Apache.
