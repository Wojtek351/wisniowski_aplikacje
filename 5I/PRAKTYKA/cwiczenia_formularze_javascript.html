JavaScript – formularze – ćwiczenia praktyczne

Ćwiczenia utrwalają odczytywanie danych z różnych elementów formularza, sprawdzanie zaznaczenia pól, wykonywanie obliczeń oraz wyświetlanie wyników na stronie. W zadaniach stosuj proste i czytelne konstrukcje JavaScript.

Ćwiczenie 1 – Rejestracja uczestnika kursu

Utwórz formularz zawierający:

  • pole tekstowe „Imię i nazwisko”,
  • pole typu number „Wiek”,
  • listę select z kursami: JavaScript, PHP, C++,
  • pola radio: „stacjonarnie” i „zdalnie”,
  • checkbox „Chcę otrzymywać materiały dodatkowe”,
  • przycisk „Zapisz”.

Po kliknięciu przycisku program powinien sprawdzić, czy wpisano imię i nazwisko oraz czy uczestnik ma co najmniej 16 lat. Następnie powinien odczytać kurs, tryb zajęć i stan checkboxa oraz wyświetlić kompletne podsumowanie pod formularzem.

Jeżeli imię i nazwisko nie zostało wpisane albo wiek jest mniejszy niż 16 lat, wyświetl odpowiedni komunikat zamiast podsumowania.

Ćwiczenie 2 – Kalkulator

Utwórz dwa pola liczbowe oraz listę select, z której można wybrać: dodawanie, odejmowanie, mnożenie lub dzielenie. Po kliknięciu przycisku „Oblicz” wyświetl wynik pod formularzem.

Uwzględnij przypadek dzielenia przez zero i wyświetl wtedy odpowiedni komunikat.

Ćwiczenie 3 – Wyposażenie stanowiska komputerowego

Utwórz formularz z checkboxami: monitor, klawiatura, mysz, słuchawki, kamera internetowa. Po kliknięciu „Pokaż wyposażenie” wyświetl wszystkie zaznaczone elementy.

Jeżeli nie zaznaczono żadnego elementu, wyświetl komunikat „Nie wybrano wyposażenia”. Nie korzystaj z Array.from() ani map() – sprawdzaj pola w prosty sposób.

Ćwiczenie 4 – Zamówienie

Utwórz formularz pozwalający wybrać produkt z listy oraz podać liczbę sztuk. Przyjmij ceny: klawiatura – 120 zł, mysz – 80 zł, słuchawki – 150 zł.

Dodaj checkbox „Dostawa kurierska +15 zł”. Po kliknięciu „Oblicz koszt” program ma obliczyć cenę produktów, doliczyć dostawę tylko wtedy, gdy checkbox jest zaznaczony, i wyświetlić końcową kwotę.

Sprawdź również, czy liczba sztuk jest większa od zera.

Ćwiczenie 5 – Kopiowanie i modyfikowanie wartości pól

Utwórz dwa pola tekstowe. Użytkownik wpisuje tekst do pierwszego pola. Po kliknięciu przycisku „Kopiuj” jego zawartość ma zostać wpisana do drugiego pola.

Dodaj drugi przycisk „Wyczyść”, który usuwa zawartość obu pól. W tym ćwiczeniu wykorzystujesz .value zarówno do odczytu, jak i do zapisu.

Ćwiczenie 6 – Konfigurator komputera

Utwórz formularz zawierający:

  • pole tekstowe na nazwę właściciela zestawu,
  • select z procesorami: Ryzen 5 – 800 zł, Ryzen 7 – 1400 zł, Ryzen 9 – 2100 zł,
  • radio z ilością RAM: 16 GB – 200 zł, 32 GB – 350 zł, 64 GB – 650 zł,
  • checkbox „System Windows +500 zł”,
  • checkbox „Montaż komputera +150 zł”.

Po kliknięciu „Podsumuj” wyświetl właściciela zestawu, wybrane podzespoły/usługi oraz całkowity koszt. Jeżeli nie wpisano właściciela albo nie wybrano ilości RAM, wyświetl komunikat o brakujących danych.

Nowy element – formularz może reagować bez przycisku

Do tej pory funkcja była najczęściej wykonywana po kliknięciu przycisku. JavaScript może jednak reagować od razu na zmianę elementu formularza.

Zdarzenie change

change występuje, gdy zmieni się wartość elementu formularza. Dobrze nadaje się np. do checkboxów, pól radio i list select.

<input type="checkbox" id="zgoda" onchange="pokazInformacje()">
<label for="zgoda">Pokaż dodatkowe informacje</label>

<p id="wynik"></p>

<script>
function pokazInformacje() {
    let pole = document.getElementById("zgoda");
    let wynik = document.getElementById("wynik");

    if (pole.checked) {
        wynik.textContent = "Dodatkowe informacje są widoczne.";
    } else {
        wynik.textContent = "";
    }
}
</script>

Nie ma tutaj przycisku. Zaznaczenie lub odznaczenie checkboxa automatycznie uruchamia funkcję.

Zdarzenie input

input reaguje podczas zmieniania zawartości pola. W polu tekstowym funkcja może więc wykonywać się przy każdym wpisanym lub usuniętym znaku.

<label for="imie">Imię:</label>
<input type="text" id="imie" oninput="pokazTekst()">

<p id="wynik"></p>

<script>
function pokazTekst() {
    let imie = document.getElementById("imie").value;
    let wynik = document.getElementById("wynik");

    if (imie == "") {
        wynik.textContent = "";
    } else {
        wynik.textContent = "Witaj " + imie;
    }
}
</script>

Jeżeli użytkownik wpisze np. Adam, napis „Witaj Adam” pojawi się od razu – bez zatwierdzania formularza.

Ćwiczenia – reakcja bez przycisku

Ćwiczenie 7 – Podgląd tekstu

Utwórz pole tekstowe „Wiadomość”. Pod nim umieść akapit. Podczas wpisywania tekstu jego zawartość ma być automatycznie wyświetlana w akapicie. Nie dodawaj przycisku.

Ćwiczenie 8 – Pokazywanie informacji

Utwórz checkbox „Pokaż regulamin”. Po zaznaczeniu pod checkboxem ma pojawić się krótki tekst regulaminu. Po odznaczeniu tekst ma zniknąć.

Ćwiczenie 9 – Automatyczny wybór

Utwórz listę select z trzema językami programowania: JavaScript, PHP i C++. Po zmianie wyboru pod listą ma natychmiast pojawić się napis „Wybrano: ...”. Nie używaj przycisku.

Ćwiczenie 10 – Licznik znaków

Utwórz pole tekstowe. Podczas wpisywania pod polem ma być na bieżąco wyświetlana liczba wpisanych znaków, np. „Liczba znaków: 8”. Wykorzystaj właściwość .length odczytanego tekstu.

Zadanie podsumowujące

Utwórz formularz zamówienia biletu na wydarzenie. Formularz powinien zawierać imię i nazwisko, wybór rodzaju biletu z listy, liczbę biletów, wybór miejsca za pomocą radio oraz co najmniej dwa dodatki jako checkboxy.

Program ma obliczać końcową cenę i wyświetlać czytelne podsumowanie. Samodzielnie ustal ceny biletów i dodatków. Zadbaj o sprawdzenie podstawowych danych przed wykonaniem obliczeń.

Dodatkowo: jeden wybrany element formularza powinien reagować automatycznie na zmianę bez użycia przycisku.
